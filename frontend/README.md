# DSVendas — Frontend

Aplicação React deste projeto. A documentação completa (visão geral, pré-requisitos, instalação, testes, roadmap, licença etc.) está no [README principal do repositório](../README.md).

## Comandos rápidos

```bash
npm install
npm start      # http://localhost:3000
npm run build  # gera a pasta build/ pronta para deploy
```

Veja a variável de ambiente `REACT_APP_BACKEND_URL` em [`.env.example`](./.env.example).
